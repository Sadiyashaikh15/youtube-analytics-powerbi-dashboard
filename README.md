# YouTube Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive YouTube Analytics Dashboard built using Microsoft Power BI
to analyze video performance, views, likes, comments and engagement.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Dashboard Metrics

- Total Views
- Total Likes
- Total Dislikes
- Total Comments
- Total Videos
- Engagement Rate

## 🔍 Analysis

The dashboard provides insights into:

- Monthly views trends
- Top-performing YouTube channels
- Channel-wise views comparison
- Engagement distribution
- Overall YouTube performance
